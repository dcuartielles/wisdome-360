# Hand-in

Every Track A film is joined into one reel and played from one machine, so a file that doesn't meet the [delivery spec](../reference/delivery-spec.md) can't be played. The deadline is **Friday 13 November, 08:00**, the morning of the dry run, so there is no time to fix a file after that.

| | |
|---|---|
| Deadline | **Friday 13 November, 08:00**, for Track A films and Track B fallback recordings |
| Where | The assignment on Canvas |
| Format | The [delivery spec](../reference/delivery-spec.md): 2048 × 2048, 30 fps, H.264 at 60 Mbit/s, audio as separate WAVs |
| Length | Track A: **90–180 s**. Track B fallback: as performed |
| Running-order number `##` | Issued on Wednesday. It goes into your file names |

## File names

Exactly like this, with your running-order number and group name:

```text
Track A   A07_teamname_TITLE_2048x2048_30fps.mp4
          A07_teamname_TITLE_48k16_L.wav
          A07_teamname_TITLE_48k16_R.wav          (… _C _LFE _Ls _Rs for 5.1)

Track B   B03_teamname_TITLE/
            fallback/B03_teamname_TITLE_2048x2048_30fps.mp4
            audio/…_L.wav  …_R.wav
            runbook.md      how to start your system, step by step
```

Fixed names, one resolution and separate audio make joining a dozen films a short scripted job on Friday morning. A wrongly named file is the one that gets left out.

## Checklist

Run it on the files you are about to upload, not on an earlier version.

- [ ] Everything in the [delivery spec checklist](../reference/delivery-spec.md#checklist) passes.
- [ ] File names follow the pattern exactly, including your running-order number.
- [ ] Track B: the fallback recording exists, meets the spec, and is in the folder.
- [ ] Track B: `runbook.md` tells a stranger how to start your system in under two minutes.
- [ ] Track B: you have tested your connection route, either **NDI + Dante** over two Ethernet links or **HDMI** (stereo), and you know which one you will use. See [Connecting a live piece](../reference/connecting.md).

## Friday

- **08:00** Files delivered. Late files miss the dry run.
- **Morning:** dry run in the dome, in running order. Note what looks wrong; you can fix small things over lunch.
- **Afternoon:** presentations. Three minutes per group to explain your decisions, in the dark, in the dome.

Track B: bring your laptop and charger, and either two Ethernet adapters (NDI + Dante) or an HDMI cable, plus the fallback file on a USB stick.
