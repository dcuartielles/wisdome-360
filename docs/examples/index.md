# Examples

Ten worked examples, one per technology plus three utilities. Five render or run as they stand; the others are recipes with working code for software you install first. Each one makes the same five decisions on purpose (see [Where to put things](../reference/comfortable-zone.md#the-five-decisions-every-example-makes)), so once you have read one, the others are quick.

| # | Name | Tool | Track | What it shows |
|---|---|---|---|---|
| EX-01 | Drift | Blender / Cycles | A | A 3-D scene through a tilted fisheye camera |
| EX-02 | Tide | Python + numpy | A | Generating every frame of a dome master in code |
| EX-03 | Pulse | WebGL / GLSL | B | A live, microphone-reactive shader in one HTML file |
| EX-04 | Chorus | p5.js | A or B | The gentlest entry point, runs offline |
| EX-05 | — | TouchDesigner | B | Recipe + two GLSL TOPs: zone guide, 360 footage → dome master |
| EX-06 | — | Unity + DomeTools | B | Placing objects by angle, audience input from a microphone |
| EX-07 | — | OpenSpace | B | A custom asset and a timed tour |
| EX-08 | Flat to Dome | HTML / Python / ffmpeg | any | Slides, photos and 16:9 video → dome master |
| EX-09 | Type size | Python + Pillow | any | Test card: how small can text be |
| EX-10 | Flight | Python + OpenCV | any | Green-screen footage keyed and flown around the room |
