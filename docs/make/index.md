# Make

Two ways to make work for the dome. Pick one and follow it from top to bottom.

| | [Making a film](film.md) | [Making a live piece](live.md) |
|---|---|---|
| You make | A rendered dome-master video | A program that draws the dome master in real time |
| Typical tools | Blender, Python, p5.js (saved frames), any video editor + EX-08 | TouchDesigner, Unity, WebGL, p5.js, OpenSpace |
| You rehearse with | The Dome Simulator: **Open file** | The Dome Simulator: share a window, or look through a USB HDMI capture card |
| You deliver | Video + WAVs in the [delivery spec](../reference/delivery-spec.md) | Your laptop, connected by [HDMI for the picture and Dante for the sound](../reference/connecting.md), plus a fallback recording |

**Never programmed?** [Live slides from zero](live-slides-from-zero.md) takes you step by step from installing Node.js and VS Code to a dome slide you changed yourself, with the difficulty of each step marked.

MaU students: Track A is a film, Track B is a live piece. Deadlines are on [Hand-in](../course/hand-in.md).
