# Workflows

A workflow is the path from your idea to what appears in the dome on Friday. There are two, one per track. Pick yours and follow it from top to bottom.

| | [Track A — a film](track-a.md) | [Track B — live](track-b.md) |
|---|---|---|
| You make | A rendered dome-master video | A program that draws the dome master in real time |
| Typical tools | Blender, Python, p5.js (saved frames), any video editor + EX-08 | TouchDesigner, Unity, WebGL, p5.js, OpenSpace |
| You rehearse with | The Dome Simulator: **Open file** | The Dome Simulator: **Share a window**, a capture card, or NDI |
| You hand in | Video + WAVs by Friday 08:00 | Fallback video + WAVs + runbook by Friday 08:00, laptop at the dry run |
